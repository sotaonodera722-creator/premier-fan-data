# 需要調査（2026-09-12）

> [competitors.md](competitors.md) が残した最大の未知数「『その選手はレギュラーなのか』に検索需要があるか」に答えるための調査。
> **前回の調査と違い、今回は日本の Google（google.co.jp）に直接アクセスできた。**順位は目安ではなく実測。

**結論を3行で**

1. **需要はある。**ただし前提としていた形ではない。人は「何番手か」ではなく **「なぜ出ていないのか」** と検索する
2. **その需要は小さく、そして跳ねる。**平常時ほぼゼロ、ニュースが出た日だけ急騰する。**記事媒体が強いのは構造的に正しい**
3. **サイトはまだ1ページもインデックスされていない。**検索戦略の議論より、これが先

## 0. この調査の方法と限界

**使った手段**

| 手段 | 何が分かるか |
|---|---|
| Google サジェストAPI（`hl=ja&gl=jp`） | 実際に検索されている語。**サジェストに出る＝一定の検索量がある** |
| Bing サジェスト（`market=ja-JP`） | 上の裏取り |
| google.co.jp の実検索 | 誰が実際に上位にいるか（**今回初めて実測できた**） |
| Google トレンド（日本・過去12か月） | 語の**相対的な**検索量と時間変化 |
| 競合サイトのHTML・sitemap・robots.txt 直接読み | 使っている広告・解析・データ源 |

**限界**

- Google トレンドは**相対値**であり、実数（月間何回検索されたか）は出ない。絶対数が要るなら Google 広告のキーワードプランナー（要 Google 広告アカウント）が必要
- サジェストに出ることは「検索量がゼロではない」証拠だが、**量の大小は示さない**
- 検索順位はログアウト状態での取得。パーソナライズや地域で多少変動する
- 笹川スポーツ財団の「インターネット観戦率」の設問定義（過去1年か、頻度か）は未確認。**信頼度：中**

## 2. 日本のプレミアリーグ視聴者はどれくらいいるか

### 母数（最も確度の高い数字）

**笹川スポーツ財団「スポーツライフ・データ2024」**（全国18歳以上 3,000人・300地点、2024年6〜7月調査）

| 項目 | 率 |
|---|---|
| **海外プロサッカー（欧州・南米など）をインターネットで観戦** | **3.6%**（男性 6.6% / 女性 0.7%） |
| サッカー日本代表戦をインターネットで観戦 | 4.1% |
| Jリーグをインターネットで観戦 | 3.0% |
| サッカー日本代表戦をテレビで観戦 | 36.4% |
| Jリーグを直接観戦（スタジアム） | 4.4% |

**概算（推定・信頼度 中）**

```
18歳以上人口 約1億人 × 3.6% ≒ 約360万人
```

これが**欧州サッカーをネットで観る人の外枠**。プレミアリーグに限れば、さらに内数。
（丸めた概算。設問の定義（過去1年か常習か）が未確認のため、実際の「毎節観る層」はこれより大幅に少ない）

**構造的に重要なのは、テレビの日本代表戦 36.4% と、ネットの海外サッカー 3.6% の間にある10倍の断層。**
`product-spec.md` の A→B→C 変換は、この断層を越えさせる試みにあたる。数としては相当に厳しい坂。

### 有料視聴者の規模

- **U-NEXT 有料会員 500万人突破**（2025年11月発表、日本企業初）。ただしこれは**サービス全体**であり、サッカーパック契約者数ではない
- プレミアリーグは **U-NEXT サッカーパックで全試合独占**（2024-25〜2030-31の7年契約。今季で3季目）
- 年間2,800試合以上を配信（ラ・リーガ、エールディヴィジ、FAカップ等を含む）

**サッカーパック単体の契約者数は公表されていない。**外部から確定させる手段は見つからなかった。

## 7. この調査から言えること

**「レギュラーなのか」は、サイトの柱にはできない。**需要はあるが小さく、山はニュース日に集中し、
そこでは記事媒体が構造的に強い。**独自性としては本物だが、集客エンジンにはならない。**

一方で、調査中に見えた**まだ試していない道**は3つある。いずれも今回の実測に裏付けがある。

1. **テキストを持つ** — 上位にいる個人サイトは全員、記事を書いている。football-wire は週次連載で64本。
   このサイトは956ページで0本。**Googleに読ませる文章が無いことが、序列の空白より重い問題**
2. **「欧州組」の語に寄る** — `欧州組 日本人選手 成績` では **football-wire・note・蹴り道・海外組ナビという個人勢が1ページ目にいる**。
   「プレミアリーグ」の語より、個人が入り込める余地が実測で確認できた唯一の領域
3. **配信の入口を実用ページとして持つ** — football-wire の `/stats/schedule/unext` 型。
   「どこで見れる」のレビュー記事（アフィリエイト激戦区）ではなく、
   **「今週この選手の試合はどこで観られるか」という毎週更新の実用ページ**。競合は既にやっている

**ただし、その前にインデックスされること。**それが済むまで、上の3つはどれも実行する意味がない。
