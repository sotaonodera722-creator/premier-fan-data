## 2026-09-09 — 検出した4件の修正

**対象**: [src/lib/data.ts](../src/lib/data.ts) の出場時間導出・名前照合・選手名簿
**判定**: 不変条件 **130件中 不合格0 / 注意11**。`npm run lint` / `npm run build` も通過

### 直したもの

**① 交代イベントが「ピッチにいない選手」を退場させていた（R4）**

`computeMatchMinutes` と `computeSquadMinutesByLineupId` を、**ピッチ上の11人を追跡する**方式に
書き換えた。出場時間は「入った時刻から出た時刻まで」で測る。以前は交代イベントの分数を
そのまま代入していたため、2つの誤りが同時に起きていた。

- ベンチの選手にOUTイベントが付くと、出ていない試合に出場時間が生まれる
  （第3節 Man City の Enzo Fernández に76分。修正後は0分）
- 途中出場した選手が後で交代すると、投入時刻を無視して時計の数字がそのまま入る
  （60分投入・80分交代なら80分と記録されていた。正しくは20分）

**② 名前照合が略称と翻字の重複を扱えなかった（R4）**

`partwiseMatch`（語ごとの照合。"S. W. Egeli" ↔ "Sindre Walle Egeli"、
"Y. Yarmolyuk" ↔ "Yehor Yarmoliuk"）、`prefixMatch`（後ろの語が落ちた形。
"Alysson Edward" ↔ "Alysson Edward Franco da Rocha"）、`initialAndSurnameMatch`
（"I. Fatawu" ↔ "Abdul Fatawu Issahaku"）の3規則を追加。

**③ 照合が「最初の一致」を返していた（R6 — 修正の途中で自ら作り込んだ）**

②の規則を足した直後、Coventry City で「B. Thomas-Asante」が同じクラブの
「Bobby Thomas」に一致し、Thomas-Asante の交代が別人に付いた。緩い規則を足すなら、
**候補は最も強く一致したものを選ばなければならない。** `nameMatchScore` で規則に強さの
順位（完全一致5 → 構造的一致4 → 翻字3 → 単名2 → 頭文字+姓1）を与え、
`bestNameMatch` が最高得点の候補を返すようにした。

**④ 同一選手が提供元の別IDで二重計上（R5）**

`getSquadUsage` の集計キーを、名簿の選手に解決できるときは名簿IDにした。
Liverpool の Jérémy Jacquet は 160分（ローテーション）と 77分（出番待ち）の2行に
分裂していたが、正しい **237分・不動** の1行になった。

**⑤ ありえない年齢を表示していた**

`getPlayers()` が 15〜45歳の範囲外を `null` にする。表示は既存の `-` フォールバックに乗る。
生年月日の誤り自体は提供元由来で直せないので、件数は「注意」として監査が報告し続ける。

**⑥ null と 0 の区別が失われていた（R7）**

`getJapanesePlayerSummaries` の `minutes` は、ラインナップに名前があって出場0なら `0`、
一度も名前がなければ `null` を返す。以前は両方 `null` で、**3試合ベンチ入りしている遠藤航が、
一度も招集されていない選手と同じ扱い**になっていた。`src/lib/types.ts` に書かれていた契約に
実装が追いついていなかった形。現状のUIは両者を同じ文言で表示するため見た目は変わらないが、
「ベンチ入り3試合・出場なし」と書き分ける余地ができた（S09の持ち越し候補）。

### 直していないもの（提供元の欠損。監査は「注意」で報告し続ける）

- **片側しか記録されていない交代 4件**（Man City +14分 / Chelsea +8分 / Sunderland +7分 /
  Newcastle ±0分）。投入された選手は実際にプレーしているので出場時間は付ける。誰が退いたかは
  データにないので、退場者を捏造せず、ずれを `SquadUsage.imbalance` として**導出側が申告する**。
  監査はこの恒等式（実測 = 理論値 + 申告値）を検証するので、申告と実測が1分でも食い違えば
  不合格になる
- **得点イベントとスコアの不一致 6/30試合** — 導出したゴール・アシストが実際より少ない
- **生年月日の誤り 2人** — Lewis Hall、El Hadji Malick Diouf

### data-auditor の判定: **合格**（10ターン）

日本人選手9人の第3節を、ラインナップと交代イベントから手計算して突き合わせ、9人とも一致。
Jacquet の統合（237分・1行）、年齢2人の非表示、`bestNameMatch` が
"B. Thomas-Asante" を Bobby Thomas より優先すること、`getPlayerRoundUsage` と
`getPlayerAppearances` の経路一致も確認。新規の不合格なし。

マネージャー側で9人を独立に再確認済み（冨安健洋が控えで投入なし＝`benched`、
遠藤航の通算が `0`、三笘薫が `null` であることを含む）。
なお data-auditor の報告はクラブ名を2か所取り違えていた（坂元達裕と Bobby Thomas を

### 判断が要る持ち越し
